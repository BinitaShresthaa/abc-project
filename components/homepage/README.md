# Aadikavi Homepage Components

This folder contains the homepage-only UI components imported from the standalone Aadikavi homepage project.

- `HeroSlider.tsx` — hero/banner
- `AboutCampusSection.tsx` — campus introduction
- `AboutSection.tsx` — site information
- `ProgrammeSection.tsx` — bachelor/master programme cards
- `CampaignsSection.tsx` — campaign cards
- `AlumniSection.tsx` — alumni cards
- `BackToTop.tsx`, `Reveal.tsx`, `AutoScrollRow.tsx` — homepage interactions

The shared site chrome lives in `components/site/` and is mounted from `app/layout.tsx`.
